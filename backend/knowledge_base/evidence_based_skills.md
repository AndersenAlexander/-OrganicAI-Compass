# Evidence-Based Skills

Retrieval filters: evidence_based_skills, career_guidance.

Skill evidence in OrganicAI Compass is structured by source, recency, confidence, and verification need.

Evidence types include self-reported evidence, employment experience, formal education, certification, course completion, practical exercise, career experiment, portfolio project, professional project, mentor review, and user-confirmed external evidence.

Evidence strength labels are:

- Unverified
- Self-reported
- Supported
- Demonstrated
- Practically verified
- Professionally evidenced

Evidence confidence is deterministic and transparent. Prototype factors include source strength, practical relevance, recency, specificity, independent confirmation, and consistency with other evidence. The UI should avoid false precision. It should use labels such as Limited evidence, Emerging evidence, Moderate evidence, Strong evidence, and Multiple supporting sources.

Old evidence should not disappear. Recency can reduce confidence and recommend a refresh while preserving the historical record.
