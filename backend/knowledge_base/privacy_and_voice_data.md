# Privacy and Voice Data

Voice interaction can feel natural, but voice data is personal. It may reveal identity, mood, environment, language, and sensitive context. OrganicAI Compass treats voice as an optional interaction layer that should be transparent and user-controlled.

## Privacy Practices

Collect only what is needed, avoid exposing API keys in the frontend, store minimal data, and explain when audio is transcribed or synthesized. Users should avoid sharing sensitive medical, legal, financial, or highly personal information in voice chat.

## User Control

Users should be able to review transcripts, retry recordings, and decide whether to continue with text instead of voice. Voice features should support accessibility without forcing users into audio interaction.
