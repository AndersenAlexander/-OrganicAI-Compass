# Evidence-Locked Applications

Evidence-locked documents help users create more truthful job-specific CV and cover-letter drafts.

Document claims are classified deterministically:

- Supported: multiple or strong Evidence Passport links support the claim.
- Partially supported: one evidence link supports part of the claim.
- Transferable: the claim is framed as adjacent or transferable evidence.
- User-confirmed: the user explicitly confirms the factual claim.
- Unverified: no supporting evidence is linked.
- Blocked: the claim is exaggerated, unsupported, or too risky to export without acknowledgement.

Application Studio never submits applications automatically. Export creates local structured JSON and printable HTML. It explicitly disables:

- auto-apply behavior;
- ATS success guarantees;
- fabricated employer knowledge;
- unsupported seniority claims.

When a claim is blocked, the user can replace it with a safer alternative or export only after explicit warning acknowledgement. This keeps the final decision human-led and traceable.
