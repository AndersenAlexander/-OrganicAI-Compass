# Market-Aware Application Journey

OrganicAI Compass now includes a market-aware application workflow that connects existing profile data, career hypotheses, Evidence Passport records, market observations, job analysis, application documents, application tracking, and academic evaluation.

The workflow is intentionally evidence-based:

- Career recommendations remain hypotheses until supported by practical evidence.
- Market Radar shows observed local dataset signals and current active opportunities, not a single market score.
- Job Analyzer extracts correctable requirements from saved or pasted job ads.
- Application Studio creates CV and cover-letter drafts with evidence-locked factual claims.
- Application Tracker stores local application events, stages, outcomes, and recalibration suggestions.
- Research Evaluation records consented pre/post/SUS-style survey answers and workflow metrics for pseudonymous export.

The system reuses existing OrganicAI modules:

- Profile and Human Potential Map remain the source for values, strengths, languages, and goals.
- Career Compatibility and supported paths remain the source for career directions.
- Evidence Passport remains the source for skill evidence, confidence, and recency.
- My Roadmap is not changed by outcome recalibration unless the user explicitly confirms a future action.

Market data limitations:

- Demo mode uses fictional Norwegian job ads for repeatable testing.
- Live NAV integration is backend-only and disabled unless credentials are configured.
- Trend labels are limited to the observed indexed dataset and are not forecasts.
- Inactive or deleted ads are not shown as active opportunities.
