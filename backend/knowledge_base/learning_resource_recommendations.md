# Personalised Learning Resource Recommendations

OrganicAI Compass treats learning-resource recommendation as a skill-gap-driven decision support process. A recommendation should connect a selected career direction, current skill evidence, target role requirements, user learning preferences, and a verified resource record.

Resource identity must come from the curated catalogue or an authorised provider adapter. The AI coach may explain why a stored resource is relevant, but it must not invent course titles, providers, prices, ratings, URLs, instructors, or availability.

Quality is not based on popularity alone. Useful quality signals include official or primary-source status, curated verification, clear learning outcomes, appropriate prerequisites, practical exercises, project components, recent verification, accessibility, and transparent limitations.

Course completion records exposure to knowledge. Stronger evidence comes from practical exercises, portfolio projects, professional application, mentor review, or documented reflection. A course should not automatically increase a skill to an advanced level without evidence.

Adult learning and professional transition benefit from staged progression:

1. Foundations: prerequisites, core concepts, and AI literacy.
2. Applied skills: methods, tools, guided exercises, and responsible practice.
3. Practical evidence: projects, case studies, and portfolio artefacts.
4. Career validation: job-description review, professional interview, role experiment, and feedback.
5. Transition preparation: CV, portfolio, interview preparation, and targeted applications.

The recommendation engine should make uncertainty visible. It should show which user data influenced the recommendation, which filters were applied, when metadata was verified, whether the resource is affiliated, and why the resource may be limited.

External resource metadata can become stale. Prices, availability, certificates, and course structure should be checked on the provider page before purchase or enrolment.
