# Week 6 Demo Script

Status: implemented as deterministic demo.

1. Reset the demo account.
2. Open `/workspace/demo-profile/adaptive-experiments`.
3. Run adaptive analysis and review evidence gaps, ranking components and alternatives.
4. Accept or start the top experiment.
5. Record an outcome and review the evidence-capture proposal.
6. Open `/workspace/demo-profile/transition-simulator`.
7. Run a Pareto simulation, inspect the chart/table, dominated paths and constraint statuses.
8. Update constraints and compare the preserved historical simulation.
9. Add one path to the Decision Journal or create a roadmap proposal.
10. Open `/workspace/demo-profile/recommendation-robustness`.
11. Run robustness analysis and inspect rank movement, threshold crossings and dependencies.
12. Open `/workspace/demo-profile/synthetic-fairness-lab`.
13. Run the synthetic audit and inspect suites, results and limitations.
14. Open `/about/recommendation-system-card` and review excluded uses and validation status.

No live provider calls, public deployment, email sending or application submission is part of the demo.
