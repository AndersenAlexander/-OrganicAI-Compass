# Career Decision Journal

The journal records explicit user decisions and preserves the context that influenced them. It separates `SYSTEM_SUGGESTED`, `AI_EXPLAINED`, `ADVISOR_COMMENTED`, `EVIDENCE_SHOWED` and `USER_DECIDED` inputs.

Entries can link a Career Hypothesis, Evidence links, Career Experiment, Job Analysis, Application, Interview and adviser comment. Assumptions, missing information, confidence, uncertainty, reversibility, user reasoning, later outcome and lessons learned are stored separately.

Every edit or outcome creates an immutable version snapshot. Outcomes and lessons require an explicit user action. Journal activity never mutates the roadmap automatically.
