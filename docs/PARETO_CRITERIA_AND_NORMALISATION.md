# Pareto Criteria and Normalisation

Objective version: `career-transition-objectives-v1`

Minimised criteria:

- transition duration
- direct monetary cost
- weekly effort
- financial risk
- evidence gap
- capability gap
- language barrier
- dependence on uncertain assumptions

Maximised criteria:

- Personal Fit
- Capability Fit
- Market Fit
- Support Fit
- local opportunity availability
- accessibility
- reversibility
- portfolio reuse
- transferable skill reuse
- AI-change stability

Normalisation maps each criterion to a benefit value from 0 to 1 within the current comparable path set. Ties do not create dominance. Missing or incomparable values prevent dominance and are reported as uncertainty. Deterministic ordering places Pareto-optimal paths first, then by title.

The frontend chart shows two selected criteria. Pareto classification uses the complete configured criterion set.
