# TASK 17C - Conversion Homepage

## Scope

Task 17C redesigns the homepage below the existing full-width cinematic video hero slider. It is frontend presentation work only. Backend career logic, authentication, database schema, scoring, RIASEC-inspired logic and release metadata were not changed.

## Homepage Strategy

The homepage now behaves as a product journey rather than a quote-led editorial page. It moves the visitor through:

1. hero and primary conversion
2. core pillars
3. direct product explanation
4. user-controlled overview video
5. real 13-step OrganicAI product journey
6. service catalogue
7. voice-first Coach differentiator
8. benefits
9. testimonial-safe social proof architecture
10. research, explainability and trust
11. real blog insights
12. final conversion
13. footer

The main conversion remains `Start Your Diagnostic`. The voice conversion appears in the dedicated voice section and final conversion area through `Talk to OrganicAI Coach`.

## Product Journey

The journey content lives in `frontend/src/config/homeConversionContent.ts`.

The ordered steps are:

1. Natural Discovery
2. RIASEC-inspired Career Interests
3. Human Potential
4. Capability Assessment
5. Four-Layer Career Model
6. Career Hypotheses
7. Career Experiments
8. Evidence Passport
9. Recalibration
10. Market Context
11. Application Journey
12. Interview Preparation
13. Decision Intelligence

Each step includes a number, headline, concise explanation, "What you gain" line, supporting signals and a route into the implemented product where available. The RIASEC content is described only as RIASEC-inspired Career Interests and as one component of Natural Fit.

## Services

The service catalogue uses eight large groups, not a dense grid of tiny features:

- Career Discovery
- Career Direction
- Evidence & Development
- Market & Jobs
- Application Support
- Interview Support
- Decision Intelligence
- AI Support

Service routes are generated by `buildHomeRoute()` and fall back to `/diagnostic` when a profile-dependent route cannot be built.

## Voice Coach

The voice section is dedicated and prominent. It presents voice accurately as an optional interaction channel:

- users can interact through text
- where enabled and configured, users can use voice
- microphone access requires user action and consent
- voice is not presented as personality, emotion, honesty or hiring assessment
- the CTA opens the existing floating OrganicAI Coach panel
- the full Coach route remains profile-aware

The voice examples are conversational prompts only. Unsupported navigation commands are not shown.

## Testimonials

Testimonials are configured in `frontend/src/config/homeTestimonials.ts`.

Current real testimonial count: `0`.

Because no verified testimonials were supplied, the homepage renders an honest empty state and does not display fabricated users, names, companies, quotes, outcomes or metrics. To add real testimonials, insert verified entries into `homeTestimonials` using:

```ts
{
  quote: "...",
  name: "...",
  role: "...",
  context: "...",
  avatar: "/optional/path.png",
  verified: true
}
```

## Blog / Insights

The Insights section connects to the existing real blog data in `frontend/src/data/blogArticles.ts`. It renders three linked article previews and sends users to `/blog/:slug`. No mock CMS or invented published articles were added.

Current real article count: `6`.

To add articles, update `blogArticles` and the homepage will continue pulling from that source.

## Video Loading

Video media is configured in `homeVideoAssets` and rendered through `ProductDemoVideo`.

Rules:

- hero slider remains the only autoplay surface
- below-fold videos use native controls
- below-fold videos use `preload="none"`
- posters are specified for stable layout
- media stays in `/public/videos/home`
- no video binary is imported into the JavaScript bundle

To add or change journey videos, update the matching key in `homeVideoAssets` and reference it from the relevant `homeJourneySteps` item.

## Responsive Behaviour

Desktop uses alternating media/text journey blocks, wide visual sections and larger service groups. Tablet collapses journey cards into stacked blocks. Mobile stacks media, services, benefits, trust and insights while preserving journey order.

The focused Playwright tests verify desktop dark, desktop light and mobile horizontal overflow.

## Accessibility

The page keeps one H1 from the hero and uses H2/H3 section hierarchy below it. Videos have labels, posters and controls. Voice is optional and always paired with text alternatives. Focus states reuse homepage and global focus styling. Reduced motion keeps the hero readable without video sources.

## Performance Safeguards

- No new carousel or animation dependency was added.
- `ProductDemoVideo` uses `preload="none"` by default.
- The hero component still controls active autoplay.
- Below-fold videos are user-controlled.
- Content data is static TypeScript, not runtime fetched.
