# Adaptive Evidence-Gain Engine

Feature name: Adaptive Evidence-Gain Experiment Engine.

Purpose: select the smallest practical career experiment expected to reduce the most important unresolved career uncertainty while remaining proportionate in time, cost, effort, accessibility, and implementation risk.

Inputs reused:

- Active Career Hypotheses.
- Evidence Passport confidence and recency.
- Career Experiment templates.
- User constraints such as weekly learning time and learning budget.
- Prior rejected and completed experiments.

Outputs:

- Recommended experiment.
- Related hypotheses.
- Uncertainty addressed.
- Skills tested.
- Expected evidence and artifact.
- Estimated duration, effort, and cost.
- Market relevance and cross-path usefulness.
- Accessibility considerations and support options.
- Limitations and data-quality warnings.
- Lower-effort, higher-evidence, and no-action alternatives.

Important boundary: missing evidence is treated as uncertainty, not inability.

User actions:

- Accept.
- Save for later.
- Reject with reason.
- Start experiment.
- Record expected versus actual evidence gain.

Starting an adaptive experiment reuses the existing Career Experiment session model. Roadmap insertion is not automatic.
