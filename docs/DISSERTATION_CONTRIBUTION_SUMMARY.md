# Dissertation Contribution Summary

OrganicAI Compass is a research prototype for user-controlled career exploration rather than an automated career-decision system. Its technical contribution is the integration of source-separated self-report, explicit evidence-review boundaries, provenance-bearing deterministic exploration tools, and user-controlled cross-module workflow state.

The implementation contributes:

1. a Human Diagnostic to Human Potential Map workflow that treats outputs as reviewable interpretation;
2. an Evidence Passport model that separates self-report, confirmed evidence, experimental observations, market inputs, and system suggestions;
3. an explicit proposal/confirmation pattern for experiments, roadmap actions, application states, recalibration, adviser proposals, and personal decisions;
4. deterministic exploratory tools: adaptive evidence-gain experiment ranking, Pareto trade-off comparison, scenario-offset robustness inspection, and synthetic-only fairness engineering checks; and
5. technical evidence for persistence, ownership boundaries, provenance, controlled mutation, and selected interface regressions.

The evidence supports technical implementation claims. It does not establish participant benefit, predictive validity, psychometric validity, real-world fairness, labour-market completeness, improved career outcomes, or hiring outcomes. Those questions require a separately designed empirical study.
