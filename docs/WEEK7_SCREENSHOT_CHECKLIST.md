# Week 7 screenshot checklist

Capture only one purposeful image per state. Use the deterministic Demo Mode profile and label screenshots with theme, viewport and data status.

## Thesis figures

- [ ] Human Potential Map with visible layer labels and uncertainty.
- [ ] Career Hypothesis explanation showing sources, support and gaps.
- [ ] Evidence Gap with “missing evidence is not inability” language.
- [ ] Career Experiment before submission.
- [ ] Provisional Evidence proposal before explicit acceptance.
- [ ] “What changed and why?” after confirmed recalibration.
- [ ] Market provider state, source type and freshness.
- [ ] Job Analysis requirement confirmation and Evidence Lock.
- [ ] Interview preparation question with confirmed source note.
- [ ] Interview feedback rubric without an opaque single score.
- [ ] Adviser share scope with excluded private sections.
- [ ] Decision Journal entry with assumptions and uncertainty.
- [ ] Pareto Simulator with non-dominated and dominated paths visible.
- [ ] Robustness sensitivity matrix with dependency warnings.
- [ ] Synthetic Fairness Lab with synthetic-only limitation.
- [ ] Recommendation System Card and provenance trace.

## Presentation backup

- [ ] Light Mode desktop: Human Potential Map.
- [ ] Dark Mode desktop: Originality layer.
- [ ] Mobile 390×844: Market/Application or Interview Journey without horizontal overflow.
- [ ] Provider-unavailable state for NAV/live market.
- [ ] Voice-disabled fallback state.
- [ ] Demo Mode label and reset confirmation.

## Capture metadata

Record for each selected screenshot:

- route;
- theme;
- viewport;
- Demo Mode or non-demo UAT;
- provider state;
- whether the image is a thesis figure, presentation image or failure fallback.
