# Recommendation Robustness Methodology

Feature name: Recommendation Robustness and Fairness Lab.

User-specific robustness analysis varies non-sensitive inputs within plausible ranges:

- weekly learning time
- learning budget
- market-data window
- evidence recency
- support availability

Confirmed qualifications and professional history are not perturbed as though uncertain.

Metrics:

- rank stability
- fit-band stability
- top-k overlap
- score variance
- scenario agreement
- threshold-crossing count
- data-coverage confidence

Statuses:

- stable recommendation
- moderately sensitive
- highly sensitive
- data-limited
- insufficiently robust

The output includes a sensitivity matrix and a "What could change this recommendation?" section. Robustness is not presented as proof of correctness.
