# Week 7 supervisor demo script

Target duration: 8–12 minutes.

Use the deterministic Demo Mode profile only. Do not present demo records as participant data or empirical evidence. If a live provider is unavailable, keep the visible fallback label on screen.

## Narrative

1. **Problem — 45 seconds**
   Explain that career decisions often mix preference, capability, evidence, market context and uncertainty into one opaque result. OrganicAI Compass keeps those layers visible.

2. **Human Diagnostic — 1 minute**
   Show the diagnostic as an editable conversation with Natural Discovery and the Human Potential Map. Emphasise that interpretation is provisional and user-correctable.

3. **Career Hypothesis — 45 seconds**
   Open Career Compatibility and show source categories, supporting factors, conflicts and missing evidence. Say “direction to test”, not “the correct career”.

4. **Evidence Gap — 45 seconds**
   Open Career Resilience. Point to evidence confidence, recency, verification state and explicit uncertainty.

5. **Career Experiment and recalibration — 1 minute**
   Start a deterministic experiment, submit a reflection and show the provisional Evidence proposal. Explain that Evidence Passport and hypothesis state change only after an explicit user decision.

6. **Market/Application — 1 minute**
   Show provider status and source freshness first. Open a pasted or demo job analysis, confirm requirements, then show Evidence Lock on application documents. Unsupported claims remain blocked until reviewed; submission is never automatic.

7. **Interview — 1 minute**
   Show confirmed requirements feeding preparation questions, the text mock fallback and rubric feedback. Mention that voice is optional and disabled provider states remain explicit.

8. **Advisor and Decision Journal — 45 seconds**
   Show the restricted adviser scope and a journal entry with assumptions, uncertainty, provenance and later outcome. Point out that adviser feedback does not silently mutate the profile or roadmap.

9. **Originality layer — 2 minutes**
   Show, in this order:
   - Adaptive Evidence-Gain alternatives and no-action reflection;
   - Pareto paths with both non-dominated and dominated paths;
   - Robustness sensitivity and dependency explanations;
   - Synthetic Fairness limitations and the Recommendation System Card;
   - Recommendation Provenance explaining inputs, versions and available actions.

10. **Close — 30 seconds**
    State: “This is a technically validated internal release candidate. Empirical participant evaluation is pending; the system does not claim improved career outcomes, fairness certification or public production readiness.”

## Failure plan

- NAV/live market unavailable: use deterministic Demo Mode and show the provider warning.
- Voice unavailable: use text mock/interview mode and show the disabled provider state.
- Internet unavailable: use the local build, deterministic fixtures and screenshots.
- Backend restart: restart the local backend, log in again and use the saved Demo Mode profile.
- Browser extension unavailable: use the built-in pasted job text path; do not imply that capture succeeded.
- Demo state becomes unclear: use the controlled Demo reset, then refresh the profile before continuing.
