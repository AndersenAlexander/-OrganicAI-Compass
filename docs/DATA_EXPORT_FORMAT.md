# Data Export Format

Technical draft - requires legal review before public deployment.

Exports are generated by `/api/privacy/exports` and recorded in `privacy_export_artifacts`.

Format:

- Artifact extension: `.zip.enc`
- Archive payload before encryption: `manifest.json` and `personal-data.json`
- Manifest fields: generation timestamp, format, encrypted-at-rest flag, legacy orphan archive inclusion flag
- Records: tables linked to the authenticated user by `user_id`, `users.id`, or conversation ownership

Excluded values:

- Password hashes
- Refresh-token hashes
- Account-token hashes
- Request context hashes
- IP hashes
- User-agent hashes
- External provider object hashes
- Export encryption-key hashes
- Deletion ledger hashes

Exports expire according to `PRIVACY_EXPORT_EXPIRE_HOURS`.
