# Adaptive Evidence-Gain Method

Status: implemented; deterministic technical test; pending empirical validation.

The Adaptive Evidence-Gain Engine identifies evidence gaps from active Career Hypotheses, Evidence Passport confidence/recency records and existing Career Experiment templates. Missing evidence is labelled as uncertainty, not inability.

For each active template, the engine calculates visible dimensions:

- uncertainty reduction
- evidence importance
- labour-market relevance
- cross-path transferability
- portfolio value
- feasibility
- support availability
- user preference alignment
- time cost
- monetary cost
- complexity
- accessibility barrier
- repetition penalty
- evidence redundancy
- implementation risk

The output includes a recommended option, lower-effort option, higher-evidence option, lower-cost option and no-action option. The no-action option is valid when current constraints make evidence collection unrealistic.

Completing an experiment creates an evidence-capture proposal only. Verified Evidence Passport evidence requires separate user review.
