# Cloud Data Protection Checklist

Technical draft - requires legal and operational review before public deployment.

- Region selection.
- Data residency.
- Subprocessors.
- International transfer.
- Encryption at rest.
- Encryption in transit.
- Backup location.
- Log retention.
- Telemetry privacy.
- Access controls.
- Administrator access.
- Deletion propagation.
- Provider agreements.
- Incident notification.
- Research-data separation.

This checklist is a technical planning artifact and does not claim legal compliance.
